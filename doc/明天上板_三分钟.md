## 2. 上电应该看到什么

```
上电     ->  PC 全屏（有 PC 视频就是它）
            画面上：8 个红点贴线 + 3 个色块 + 一行英文（左上角）
PC 停发  ->  1.5 秒后自动切【摄像头全屏】
PC 恢复  ->  自动回 PC 全屏，不用按键
没有 PC  ->  1.5 秒后是摄像头全屏（不再停在四宫格）
```

按键：**按键 1** 循环 `PC 全屏 → 四宫格 → 摄像头全屏`；**按键 2** 开关识别图层。

## 3. 红点不贴线怎么办

按这个顺序调，一次只改一个：

| 现象 | 改什么 | 现在值 |
|---|---|---|
| 红点整条偏左/偏右（两条都偏） | `SEED_L` / `SEED_R`（重捕种子） | 384 / 640 |
| 红点时有时无、亮的线也认不出 | `THR_MIN`（阈值下限） | 64 |
| 整片被当成白线 | `CT_MIN` 调大（要求对比度更高） | 28 |
| 虚线被判成实线 | `SOLID_ON` 调大 | 168 |
| 实线被判成虚线 | `SOLID_ON` 调小 | 168 |

参数在 `quad_wr_ctrl.v` 末尾 `module lane_detect` 的 `#(...)` 里。
改完 `prj/source/rtl/quad_wr_ctrl.v` **也要一起改**（综合读的是那一份）。

## 4. 只有好几个格里有红点？—— 只会有全屏那一种

识别**只在 PC 全屏做**。四宫格里 PC 被抽成 512×300，垂直分辨率减半、三格还反复发
同一幅图，画出来的点没有意义，所以干脆不开。

## 5. 已知限制（如实）

- 所有阈值都是**合成数据**下调的，真实视频的光照/装角必然要重调一次
- 夜间、逆光没碰；车辆检测按 11-02 的决定没做
- 急弯跟丢后会在第 3 帧放宽窗重捕，期间 `LOST` 会亮一下，正常
- **PC 端如果只发 900 块（四宫格布局），全屏会有 1/4 区域一直是旧的** ——
  这要 PC 端改成发 1200 块，板子上补不出来（见 README 38.7）
